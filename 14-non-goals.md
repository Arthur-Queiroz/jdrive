# Non-Goals for MVP

The following features must not be implemented unless the specification is explicitly revised.

- Multiple-user collaboration
- Public file sharing
- Public share links
- Folder hierarchy
- File previews
- PDF rendering
- Office document rendering
- File editing
- Image editing
- File versioning
- Automatic sync client
- Desktop application
- Native mobile application
- WebDAV
- S3-compatible object storage
- Google Drive integration
- OneDrive integration
- Dropbox integration
- Redis caching
- Background job queues
- Antivirus scanning
- Automatic duplicate removal
- File compression
- File conversion
- Advanced analytics
- Audit logs
- Dedicated observability stack

The MVP is a private personal file-transfer application, not a cloud-storage platform.
